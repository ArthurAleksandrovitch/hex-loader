# Hex Loader

Графическое приложение для загрузки HEX-файлов в Arduino.

Проект разработан на языке **Go** с использованием библиотеки **Fyne**. Для загрузки прошивки используется `arduino-cli`.

## Возможности

* выбор HEX-файла;
* автоматическое определение подключённой платы Arduino;
* выбор платы и FQBN;
* загрузка HEX-файла в Arduino;
* отображение статуса операции и прогресса;
* графический интерфейс;
* поддержка сборки проекта через GitHub Actions.

## Технологии

* **Go 1.23**
* **Fyne**
* **Arduino CLI**
* **Git**
* **GitHub Actions**
* **GitHub Releases**

## 5. Настройка GitHub Actions

Для автоматической проверки и сборки проекта был создан workflow GitHub Actions.

Workflow выполняет следующие действия:

1. получает исходный код репозитория;
2. устанавливает Go;
3. устанавливает системные зависимости Fyne;
4. проверяет форматирование исходного кода;
5. загружает зависимости;
6. собирает приложение;
7. сохраняет собранный бинарный файл как Artifact.

Файл workflow:

`.github/workflows/ci.yml`
